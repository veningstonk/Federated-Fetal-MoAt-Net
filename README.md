# Federated-Fetal-MoAt-Net
Federated learning framework for privacy-preserving fetal ultrasound diagnostic plane classification using Fetal MoAt Net (MobileNetV2 + custom attention). Benchmarks FedAvg, FedProx, SCAFFOLD, and Contrastive Prototype FL on FPUS23 and FETAL_PLANES_DB across IID and Non-IID settings.
